- 작성일: 2026-11-16
- 기준 시제품: `관리 프로그램/자녀학비보조 관리 프로그램.html` v1.4 (원본 소스는 같은 폴더 `.src_without_library.html`)
- 근거 규정: 교직원 자녀 학비보조에 관한 규정(2024.12.26. 개정)
- 저장 위치: `chickensmell/work` 저장소 `child-tuition` 브랜치(2026-11-16 비공개 저장소 `child-tuition`에서 옮김). 소스 `child-tuition/src/index.html`, 배포본 `child-tuition/index.html`

## 1. 목적과 범위

### 가. 왜 만드는가
1) 분기마다 엑셀과 종이 서류로 검토하면서 같은 오류가 반복됨
   가) 서류를 보고 금액을 손으로 옮기다 생기는 오타(예: 102,000 → 120,000)
   나) 타 부서(교무팀·의전원) 회신 정정본을 덮어쓰지 않아 틀린 임용일이 그대로 쓰임
2) 규정 판단(재직기간, 자녀 수, 학기 수, 한도)과 금액 계산을 사람이 매번 다시 함

### 나. 하는 일
1) 신청 접수: 스캔 추출 파일·지원내역 엑셀 가져오기, 직접 입력
2) 재직 확인: 확인 요청 엑셀 내보내기, 회신 불러오기(변경 미리보기·이력)
3) 검토·판정: 규정 자동 점검, 실 지급금액 계산, 지급/보류/제외 판정
4) 기안·업로드: 신청내역 엑셀, 기안문 초안, 출납정보·개인지급등록 업로드 파일
5) 명부: 교직원(교번·병원 사번·확인 임용일·급여계좌), 자녀별 누적 학기
6) 분기 마감: 누적 학기 반영, 다음 분기 계좌 비교 기준

### 다. 하지 않는 일
1) 스캔 PDF를 직접 읽지 않음(OCR 없음). 스캔은 Claude가 읽어 "스캔 추출 파일"로 만들고 프로그램이 가져옴
2) 학사·인사 시스템과 직접 연동하지 않음(엑셀 주고받기)

### 라. 운영 조건
1) 학교 PC에서 인터넷 없이 실행(오프라인). 교직원 개인정보·계좌가 외부로 나가지 않아야 함
2) 시제품은 단일 HTML + SheetJS 0.18.5 내장, 데이터는 브라우저 localStorage(`child-tuition-v1`) + JSON 백업 파일
3) 코드로 옮길 때도 이 조건(로컬 실행, 외부 전송 없음)을 유지하는 것을 전제로 함

## 3. 규정 판단 기준

### 가. 용어(제2조)
1) 교직원: 대학교 소속으로 급여를 받는 전임교원과 정규직원
2) 자녀: 같은 호적의 직계자녀
3) 학자금
   가) 고등학교: 수업료, 운영회비(육성회비), 입학금
   나) 대학교(학부과정만): 수업료, 입학금, 기성회비
   다) 급식비·기숙사비 등은 제외

### 나. 지급 제한(제3조)
1) 학비 면제·무상 학교, 보훈 면제, 졸업 후 동등 이하 학력 재입학 → 제외
2) 타 기관 지원(장학금 포함)은 빼고 실 납부금액만 지원
3) 휴직·정직 중 지급 안 함
4) 신청기간·지급시기 지난 건 소급 안 함
5) 당해 학기 지급 후 사직하면 전액 반환

### 다. 고등학교(제4조)
1) 재직 3년 미만: 자녀 1명, 3년 이상: 자녀 3명
2) 분기별 50만원 한도 내 실 납부금액
3) 지급 시기: 3·6·9·12월

### 라. 대학교(제5조)

| 구분 | 재직기간 | 자녀 수 | 한도 | 총 학기 |
|---|---|---|---|---|
| 교직원 | 3년 이상 10년 미만 | 1명 | 학기당 500만원 | 8학기 |
| 교직원 | 10년 이상 | 3명 | 1인당 500만원 | 1인당 8학기(총 24) |
| 보직자 | 2년 이상(처장 3년 이상) | 1명 | 500만원 | 8학기 |
| 보직자 | 5년 이상 | 3명 | 1인당 500만원 | 1인당 8학기(총 24) |

1) 보직자: 총장, 부총장, 대학원장, 학장, 처장
2) **총 학기 범위 안에서 대상 자녀와 수를 조정할 수 있음(2024.12.26 신설)**
   가) 예: 자녀 3명이면 10회·7회·1회처럼 나눠도 됨(사용자 확인)
   나) 그래서 한도 판단은 "신청인 총 학기"로 하고, 자녀별 8학기 초과는 참고 표시만 함
   다) 자녀 수 조정 부분은 시제품에서 아직 반영 안 함(자녀 수 점검은 그대로) → 확정 필요
3) 지급 시기: 3월(1학기), 9월(2학기). 2·4분기에 대학생 신청이 있으면 경고

### 마. 재직기간(제6조)
1) 교원: 전임교원 임용 이후, 직원: 정규직원 임용 이후
2) **학교 전임·정규직 임용일만 사용. 병원 최초 임용일 아님**(신청서 입사일자는 병원 날짜인 경우가 많음)
3) 분기별 기준일: 1분기 03-01, 2분기 06-01, 3분기 09-01, 4분기 12-01
4) 근속 개월 = (기준일 − 확인 임용일), 일이 모자라면 1개월 뺌

### 바. 업무 관행(사용자 확인)
1) 구양식 신청서도 필요한 내용이 다 있으면 인정
2) 가족관계증명서는 발급 기준(배우자·학생 등) 상관없이 신청인 정보가 들어 있으면 인정. 주민등록등본도 가능
3) 신청서에 계좌가 없으면 급여계좌로 지급(흔함)
4) 병원 교수는 신청서에 병원 사번을 적는 경우가 많음 → 최종적으로 교번 필요(인사담당 문의 또는 시스템 확인)
5) 누적 신청횟수는 **신청인 기준**으로 셈. 자녀 이름만으로 합치지 않음

## 5. 금액 계산

### 가. 영수증 항목 자동 분류
1) 제외 단어가 있으면 제외: 학생회, 급식, 기숙, 생활관, 교재, 앨범, 보험, 동문, 수학여행, 체험, 방과후, 간식, 교복, 실습, 행사, 우유, 후원, 발전기금, 단체복, 졸업
2) 인정 단어
   가) 고등학생: 수업료, 운영, 육성, 입학금, 등록금
   나) 대학생: 수업료, 등록금, 입학금, 기성회
3) 사람이 (인정)/(제외)로 직접 지정하면 그 값을 따름
4) 그 밖의 항목(예: 교육비, 건강공제회비, 교지대)은 인정 안 함 → 화면에서 확인

### 나. 계산식
```
인정액(paid)   = 인정 항목 합계 (항목이 있는데 인정 항목이 0이면 0, 항목이 없으면 null)
실납부(base)   = paid − 타기관지원 (paid가 null이면 신청금액)
한도(limit)    = 고등학생 500,000 / 대학생 5,000,000
실 지급        = min(base, limit, 신청금액)   ※ 신청금액이 비어 있으면 min(base, limit)
base ≤ 0 이면 0원(지급 불가)
```

### 다. 신청금액과 실 지급금액이 다를 때 사유 문구
1) 제외 항목 금액(예: "학생회비 10,000원 제외")
2) 영수증 인정액이 신청금액과 다름
3) 장학금·타기관 지원 N원 차감
4) 실납입 0원(장학금 등)
5) 한도 적용
6) 신청금액까지만 지급
- 신청금액 = 실 지급금액이면 사유 없음

## 6. 자동 점검 목록

등급: **오류**(지급 불가, 예외 지급 시 사유 필수) / **확인**(원본 대조 필요) / **참고**

| 등급 | 점검 | 조건 |
|---|---|---|
| 확인 | 임용일 미확인 | 확인 임용일 없음 |
| 참고 | 신청 임용일 상이 | 신청서 입사일 ≠ 확인 임용일(확인일 적용) |
| 오류 | 재직기간 미달 | 대학: 3년 미만(보직 2년, 처장 3년) |
| 오류 | 자녀수 초과 | 같은 신청인·같은 구분 신청 수 > 지원 가능 자녀 수 |
| 오류 | 교번 미확인 | 교번이 TEMP- |
| 오류 | 신분 | 휴직·정직·퇴직·임상교수 전환 등 |
| 오류 | 전임교원 아님 | fulltime=false |
| 오류 | 같은 자녀 중복 신청 | 같은 분기·신청인·자녀·구분이 2건 이상 |
| 확인 | 대학 학자금 지급 분기 | 대학생인데 2·4분기 |
| 오류 | 학부과정 아님 | grad=true |
| 참고 | 자녀 학기 | 자녀별 8학기 초과(총 학기 안에서 조정 가능) |
| 오류 | 총학기 초과 | 신청인 누적 + 1 > 8(1명 대상) 또는 24(3명 대상) |
| 오류 | 서류 없음 | 신청서 / 가족관계증명서·등본 / 납입영수증 |
| 오류 | 영수증 불가 서류 | 고지서·통장사본 등 |
| 확인 | 영수증 원본 아님 | receiptType=사본 |
| 확인 | 확인란 서명 미확인 | 신청서 제5항 서명 없음 |
| 참고 | 국외학교 | 학부과정·학자금 항목 확인 |
| 오류 | 신청기한 경과 | 접수일 > 마감일 |
| 확인 | 영수증 금액 미입력 | 인정액 null |
| 확인 | 신청서 금액 ≠ 영수증 금액 | |

## 10. 누적 학기 계산

```
자녀 누적(이번 분기 전) = children.base
                       + Σ(마감된 이전 분기 중 baseQ 이후, 이 신청인·이 자녀·대학생·판정 "지급" 건 수)
신청인 누적 = 그 신청인의 모든 자녀 누적 합
총 학기 한도 = 지원 가능 자녀 3명이면 24, 1명이면 8
```
- 시작값(base)은 과거 이력 파일 또는 지원내역 비고("자녀 n회")에서 채움. 명부 화면에서 수동 보정 가능
- 고등학생 횟수는 한도 판단에 쓰지 않지만 표시용으로 보관 권장

## 11. 스캔 추출 작업 기준(Claude 또는 담당자가 할 때)

1) 기관별 PDF(한 파일 10MB 이하 권장, 큰 파일은 업로드 중 텍스트로 바뀌어 스캔 장이 빠짐)
2) 한 신청 건당: 신청서 → 영수증 → 가족관계 서류 순으로 읽음
3) 영수증 항목은 모두 옮기고 인정 외 항목에 (제외) 표시
4) 신청서에 계좌가 없으면 계좌구분 "급여"
5) 병원 사번은 "신청서 사번" 열에, 교번을 알면 "교번/사번" 열에
6) 확인필요에 남길 것: 손글씨 판독 불확실, 발급일이 오래된 서류, 병원 인사시스템 화면을 가족관계 증빙으로 낸 경우, 외화(원화 환산 필요), 분할납부·처리 중 결제, 영수증 결제일이 신청일 이후, 신청서와 지원내역 학년·입사일 차이, 다른 신청서와 같은 계좌번호
7) 장학금 감면액은 타기관지원 열에
