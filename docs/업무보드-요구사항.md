# 나의 업무 보드: 요구사항 정리

- 최초 작성: 2026-11-16
- 구현본: `board/index.html` (claude.ai 앱으로 게시)
- 앱 주소: https://claude.ai/artifact/GuS4JDJZhQw2VzSLAK9aMu
- 변경할 때마다 맨 아래 **6. 변경 이력**에 한 줄씩 추가합니다. 요구사항 자체가 바뀌면 해당 항목도 함께 고칩니다.

## 1. 개요

### 가. 목적
사립대학교 총무처 총무팀 직원(복지·교육 담당)이 혼자 쓰는 업무 대시보드. 해야 할 업무를 목록으로 보고, 체크박스·진행상황·처리 절차·진행 기록을 관리하며 계속 업데이트한다.

### 나. 사용 환경
1) Claude 앱(claude.ai) 안의 앱으로 사용. 별도 서버·외부 데이터베이스(Supabase 등)는 쓰지 않음
2) PC 위주, 휴대폰도 사용 (반응형)
3) 본인만 접근 (다른 사람 읽기·쓰기 불가)
4) PC와 휴대폰이 같은 데이터를 봄 (claude.ai 앱 저장소 사용)

### 다. 관리 방식
1) 화면 코드: 이 저장소 `board/index.html`에서 고치고, 같은 앱 주소로 다시 게시
2) 요구사항·변경사항: 이 파일에 정리하고 변경 이력을 계속 추가
3) 업무 데이터(업무명, 메모, 진행 기록 등): 앱 저장소에만 있음. 저장소(GitHub)에는 넣지 않음

### 라. 사용자 문서 표기 규칙
보고서·기안문·안내문 번호 체계: `1.` > `가.` > `1)` > `가)`

## 2. 사용자 요구사항 (대화에서 확정된 것)

1) 업무명, 체크박스(완료), 마감일, 우선순위, 상태(대기/진행중/보류/완료), 진행률, 메모, 날짜별 진행 기록
2) 보기: 진행 업무 전체, 오늘 할 일, 이번 주, 마감 임박(3일), 보류, 완료
3) 분류: 복지 / 교육 / 정산·청구 / 상시업무 (처음 '기안·보고'였던 것을 '정산·청구'로 변경, 사용자 최종 확인은 아직 없음)
4) 반복업무: 완료 처리하면 다음 마감일로 새 업무 자동 생성
5) 연 몇 회 하는 같은 업무는 회차별로 쪼개지 말고 한 건으로 묶고, 회차는 처리 절차 체크 항목으로 관리 (예: 선물 지급 설·노동절·추석 → 1건)
6) 목록은 주기 순서로 정렬: 매월·2개월 업무가 위, 연 단위 업무가 아래
7) 비슷한 계열 업무는 붙여서 보여 주기 (예: 직장어린이집 위탁보육비 + 영유아 현황조사)
8) 인수인계서(SOP)의 처리 절차를 업무별 체크리스트로 넣고, 체크한 만큼 진행률 자동 계산
9) 인수인계서에 없는 내용은 추측해서 채우지 말고 '인수인계서에 없음' / '확인 필요'로 표시
10) 데이터는 Claude 앱 저장소에 저장. Supabase 등 외부 서비스는 쓰지 않음 (2026-11-16 결정)

## 3. 기능 명세 (현재 구현 기준)

### 가. 화면 구성
1) PC: 왼쪽 사이드바(보기 목록, 분류 목록과 건수) + 오른쪽 본문
2) 휴대폰(820px 이하): 사이드바가 상단 가로 스크롤 칩으로 바뀜
3) 본문 상단 요약 타일 4개(누르면 해당 보기로 이동)
 가) 진행 중 건수
 나) 오늘까지 마감 (지연 건이 있으면 '오늘까지 · 지연 N건', 빨간색)
 다) 이번 주 마감
 라) 이번 달 완료
4) 빠른 추가: 업무명 + 분류 + 마감일 입력 후 Enter
5) 업무 행: 체크박스, 업무명, 분류 칩, 상태 칩(대기 제외), '우선'(높음일 때), 반복 주기, '절차 n/m', '기록 n', D-day(D-n / D-day / n일 지남), 진행률 막대
6) 업무를 누르면 오른쪽 편집 패널(휴대폰은 전체 화면): 업무명, 분류, 마감일, 업무 묶음, 상태, 진행률, 처리 절차, 우선순위, 반복, 메모, 진행 기록, 삭제(화면 안에서 한 번 더 확인)
7) 예시 항목(sample)이 있으면 목록 아래에 '예시 모두 지우기' 버튼 표시

### 나. 보기별 필터 규칙 (today = 오늘 날짜 문자열 YYYY-MM-DD)
| 보기 | 조건 |
| --- | --- |
| 진행 업무 전체 | 상태가 완료·보류가 아님 |
| 오늘 할 일 | 완료·보류 아님, (마감일 ≤ 오늘) 또는 (진행중이면서 마감일 없음) |
| 이번 주 | 완료·보류 아님, 마감일 ≤ 이번 주 일요일 (지난 것 포함) |
| 마감 임박(3일) | 완료·보류 아님, 마감일 ≤ 오늘+3일 |
| 보류 | 상태 = 보류 |
| 완료 | 상태 = 완료, 완료일 최신순 |

분류 필터는 위 조건과 AND로 함께 적용.

### 다. 정렬과 묶음 ('진행 업무 전체', '보류' 보기)
1) 같은 `group` 값을 가진 업무를 한 묶음으로 만든다. group이 비어 있으면 단독 묶음.
2) 묶음 안 정렬: 주기 순위 → 마감일 → 업무명
3) 묶음의 대표 = 묶음 안 첫 업무. 묶음끼리 정렬: 대표의 주기 순위 → 분류 순서 → 업무명
4) 주기 순위: 매주 < 매월 < 2개월마다 < 수시(반복 없음) < 분기별 < 학기별 < 연 단위
5) 대표 주기가 바뀔 때마다 섹션 머리글(예: '매월 6건') 표시
6) 묶음의 두 번째 업무부터는 들여쓰기 + 연결선으로 표시
7) 그 외 보기(오늘·이번 주·마감 임박)는 마감일 → 우선순위 → 생성일 순의 단순 목록

### 라. 반복 업무
1) 반복 값: 없음(수시) / 매주 / 매월 / 2개월마다 / 분기별 / 매학기(6개월) / 매년
2) 다음 마감일: 현재 마감일(없으면 오늘) 기준 +7일 / +1개월 / +2개월 / +3개월 / +6개월 / +12개월. 월 단위는 말일 보정(1/31 + 1개월 = 2/28)
3) 반복 업무를 완료하면: 현재 건은 완료(진행률 100, 완료일 기록), 같은 내용으로 새 건 생성(상태 대기, 진행률 0, 진행 기록 비움, 처리 절차는 체크 해제한 채로 복사, 업무 묶음 유지)
4) 완료 체크를 해제하면 상태는 대기(진행률이 100이었으면 진행중·90%)로 되돌림

### 마. 진행률
처리 절차가 하나라도 있으면 진행률 = 체크한 절차 수 / 전체 절차 수 × 100 (반올림), 슬라이더 비활성. 절차가 없으면 슬라이더로 직접 입력(10% 단위). 상태를 완료로 바꾸면 100.

### 바. 저장
1) Claude 앱 저장소(`db` 기능)의 `tasks` 컬렉션, 문서 1개 = 업무 1건
2) 접근 규칙: 읽기·쓰기 모두 앱 소유자(본인)만
3) 다른 기기에서 고친 내용은 실시간으로 반영됨
4) claude.ai 밖에서 열면 저장소에 연결할 수 없으므로 '이 브라우저에만 저장되는 모드'로 동작하고 안내 문구 표시
5) 저장 공간이 가득 차면 '완료된 업무를 정리해 주세요' 안내
6) 마지막으로 본 보기는 브라우저 localStorage `wb-view`에 기억

### 사. 보안 원칙
1) 업무 내용, 직원 이름, 데이터 내보내기 파일(.json)은 GitHub 저장소에 커밋하지 않음
2) 앱은 비공개(본인만)로 유지

## 4. 데이터 구조 (업무 1건)

| 필드 | 형식 | 설명 |
| --- | --- | --- |
| title | string | 업무명 |
| cat | `welfare` / `edu` / `doc` / `routine` | 복지 / 교육 / 정산·청구 / 상시업무 |
| group | string | 업무 묶음 이름, 빈 문자열이면 단독 |
| pri | `high` / `mid` / `low` | 우선순위 |
| status | `todo` / `doing` / `hold` / `done` | 대기 / 진행중 / 보류 / 완료 |
| progress | number 0~100 | 진행률 |
| due | `YYYY-MM-DD` 또는 빈 문자열 | 마감일 |
| repeat | `''` / `weekly` / `monthly` / `bimonthly` / `quarterly` / `semester` / `yearly` | 반복 주기 |
| memo | string (여러 줄) | 규정, 시스템, 예산 과목, 보관 위치, 주의사항 등 |
| steps | `[{t: string, done: boolean}]` | 처리 절차 체크리스트 |
| logs | `[{d: 'YYYY-MM-DD', t: string}]` | 진행 기록, 최신이 앞 |
| sample | boolean | 예시 데이터 여부 (현재 모두 false) |
| createdAt | ISO 문자열 | 생성 시각 |
| doneAt | ISO 문자열 또는 빈 문자열 | 완료 시각 |
