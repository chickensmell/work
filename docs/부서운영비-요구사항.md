## 4. 자동 점검 목록

| 번호 | 점검 | 기준 | 근거 |

| 1 | 항목 재합산 | 정산서 항목 합 = 정산서 합계 = 상단 정산금액 = 접수 목록 사용액 | 상단·하단 금액이 다른 경우 잦음 |

| 3 | 지출증빙 발행 | 현금영수증(지출증빙) 발행 표시가 사진에 있어야 함, 없으면 재제출 요청 | |

2) 열: 순번(입금 단위) / 부서 / 대상자 / {첫째 달} / {둘째 달} / 입금계좌(아래 칸 예금주) / 인원 / 입금액 / (제목 없는 열) / 차액
3) 한 사람이 한 줄. 달마다 그 사람 금액(30,000 또는 15,000, 그달 대상이 아니면 빈칸)
   가) 그래서 지급액은 "인원 × 2개월"이 아니라 달별 대상자 금액의 합
   나) 예: 12월에 빠진 사람은 11월 칸만, 12월에 들어온 사람은 12월 칸만 있음
4) 순번 하나 = 입금 1건(예금주 1명). 여러 부서가 한 순번으로 묶일 수 있음. 11~12월분 23건
5) 인원 = 그 순번의 사람 수, 입금액 = 그 순번 달별 금액 합, 맨 아래 합계(인원 121, 입금액 7,035,000)
6) 차액 = 입금액 − 제목 없는 열 (일부 순번에만 수식이 있음, 용도 확인 필요)
7) 오른쪽에 "변동사항" 표(소속·성명·부서운영비·비고), 없으면 "해당사항 없음"
8) 검산: 11월 30,000원 116명 + 15,000원 4명 = 120명, 12월 30,000원 115명 + 15,000원 3명 = 118명 → 결의내역과 일치, 합계 7,035,000원 = 결의서 금액 = 출납명세서 합
