## 1. 목적과 범위

### 가. 하는 일
1) 부서운영비 정산 증빙 검토 자동화: 금액 재합산, 영수증 대조, 기간·식별번호·중복·용도 점검
2) 안내 메일 초안 작성 (종류는 10장에서 결정)
3) 기안문 초안 작성 (종류·양식은 10장에서 결정)
4) 검토 결과 보고서 작성 (기존 9~10월 보고서 형식)

### 나. 하지 않는 일
1) 회계·인사 시스템 직접 연동, 메일 직접 발송 (초안만 만들고 복사해서 씀)
2) 용도 인정·불인정 최종 판단 (사이트는 표시만 하고 담당자가 판단)

## 3. 업무 규칙

### 가. 지급 기준
1) 지급 시기: 홀수달마다
2) 지급 방법: 현금으로 각 부서 담당자에게
3) 지급액: 1인당 월 30,000원(단기근로자 15,000원) × 2개월 × 인원
   가) 예: 부서원 5명 → 30,000 × 2 × 5 = 300,000원
   나) 단기근로자 섞인 부서: (일반 인원 × 30,000 + 단기근로자 × 15,000) × 2 [추론]
4) 부서별 인원·단기근로자 수 명단: [자료 없음] → 사용자에게 받아야 함

### 나. 사용 용도
1) 회식·다과 등 부서 단합 목적
2) 결제: 대부분 계좌이체나 현금결제 후 지출증빙 현금영수증 발행
3) 지난 검토에서 확인 요청한 사례: 꽃, 비품(사무용 의자·USB 멀티충전기·핸드워시), 상품권, 퇴사자 선물, 내역과 품목 불일치(생활용품·식재료 등)
   가) 이들이 실제로 불인정 대상인지는 [자료 없음]

### 다. 정산
1) 제출물: 부서별 정산서(사용내역) + 증빙영수증
2) 접수 목록 항목: 증빙구분·부서·증빙번호·지급액·총사용액·작성자·비고
3) 증빙번호: `YYYYMMDD` + 4자리 일련번호로 보임 (예: 202610150001) [추론]
4) 통합 정산: 여러 부서가 정산서 하나로 내는 경우 있음, 비고란에 함께 적음
5) 초과 사용분 부서 부담 처리, 불인정 시 상계·반납 기준: [자료 없음]

## 4. 자동 점검 목록

| 번호 | 점검 | 기준 | 근거 |
|---|---|---|---|
| 1 | 항목 재합산 | 정산서 항목 합 = 정산서 합계 = 상단 정산금액 = 접수 목록 사용액 | 상단·하단 금액이 다른 경우 잦음 |
| 2 | 영수증 금액 | 영수증 금액 = 정산서 청구액. 일부만 현금 결제해 그 부분만 청구한 경우 현금영수증 금액과 같으면 정상 | |
| 3 | 지출증빙 발행 | 현금영수증(지출증빙) 발행 표시가 사진에 있어야 함, 없으면 재제출 요청 | |
| 4 | 식별번호 | 학교 사업자번호(설정에서 입력)와 일치. 영수증에는 가운데가 가려진 형태로 찍힘 | |
| 5 | 승인일 기간 | 해당 2개월 안 (예: 9~10월분에 7월 영수증 → 지적) | |
| 6 | 일자 오기 | 정산서 일자 ≠ 영수증 일자, 지급 이전·제출일 이후 날짜 | |
| 7 | 중복 | 부서 간·부서 안 같은 승인번호. 주문번호가 같아도 승인번호가 다르면 판매자별 분리 발행으로 보고 중복 아님 | 쿠팡 사례 |
| 8 | 용도 표시 | 꽃·비품·상품권·선물 등 키워드, 정산서 내역과 영수증 품목 불일치 | 판단은 담당자 |
| 9 | 판독 불가 | 흐리거나 잘린 영수증은 '확인 불가'로 두고 홈택스 매입 내역 대조 권장 | |

## 5. 화면 구성(안) — PC 화면만

0) 현황: 정산 회차(예: 2026년 9~10월) 선택, 단계별 진행 상태
1) 지급: 부서 명부 기준 지급액 계산표, 지급 기안·안내 초안

4) 보완 요청: 부서별 메일 초안 (지적 사항 자동 포함)
5) 결과: 검토 결과 보고서, 정산 결과 기안문 초안
